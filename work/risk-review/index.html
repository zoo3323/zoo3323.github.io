위험성평가 AI

위험성평가표를 올리면 로컬 LLM이 위험 등급·보완 사항을 평가하고, 법령과 내부 문서를 근거로 답하는 웹 플랫폼

NamJuKim

  • 회사패턴앤
  • 기간2026
  • 맡은 일1인 풀스택·LLM 개발

업로드 → AI 분석 → 보완 → 현장 점검 → 보고서를 한 흐름으로 잇는 웹 플랫폼을 프런트엔드부터 AI 파이프라인까지 1인 설계·구현. vLLM 서빙 로컬 LLM·VLM에 내부 문서 RAG·MCP 법령 조회를 결합해 인용 조문 검증·근거 기반 답변 구현.

구성

  1. 평가표 업로드엑셀(.xlsx) · 한글(.hwpx)
  2. 파싱병합 셀 · 비정형 칼럼

  3. AI 분석 · ARQ 워커 2단계

    로컬 LLM·VLMvLLM(OpenAI 호환)
    내부 문서 RAGfastembed · pgvector
    법령 조회korean-law-mcp
  4. 보완·현장 점검현장 사진 · TBM 회의록(VLM)
  5. 보고서PDF · DOCX · XLSX

Next.js · FastAPI · Supabase(PostgreSQL·pgvector)

풀어야 했던 문제

맡은 일

  • vLLM(OpenAI 호환 API) 기반 로컬 LLM·VLM 서빙, FastAPI 백엔드 연동
  • 내부 문서 RAG 파이프라인 구축: 표준 절차서·작업 지침·사고 사례 텍스트 추출 → 문장 단위 청킹 → fastembed 임베딩 → pgvector 인덱싱
  • 근거 문서를 붙여 답하는 RAG 챗봇 구현, korean-law-mcp(MCP 서버)로 산업안전보건법 조문을 실시간 조회해 없는 조문 인용(할루시네이션) 차단
  • ARQ·Redis 워커 기반 항목 분류 → 위험 등급·보완 평가 2단계 비동기 분석 파이프라인 구축
  • VLM 기반 현장 사진·TBM 회의록 분석으로 신규 위험 요인 추출
  • 병합 셀·비정형 칼럼이 섞인 엑셀(.xlsx)·한글(.hwpx) 평가표 파서 개발, 편집형 그리드·대시보드·PDF·DOCX·XLSX 보고서 내보내기 구현
