위험성평가 AI

위험성평가표를 올리면 로컬 LLM이 위험 등급·보완 사항을 평가하고, 법령과 내부 문서를 근거로 답하는 웹 플랫폼

NamJuKim

  • 회사패턴앤
  • 기간2026
  • 맡은 일1인 풀스택·LLM 개발

업로드 → AI 분석 → 보완 → 현장 점검 → 보고서를 한 흐름으로 잇는 웹 플랫폼을 프런트엔드부터 AI 파이프라인까지 혼자 설계·구현했습니다. vLLM으로 서빙한 로컬 LLM·VLM에 내부 문서 RAG와 MCP 법령 조회를 붙여, 인용한 조문을 검증하고 근거와 함께 답합니다.

맡은 일

  • vLLM(OpenAI 호환 API)으로 로컬 LLM·VLM을 서빙하고 FastAPI 백엔드에 연동
  • 내부 문서 RAG: 표준 절차서·작업 지침·사고 사례를 텍스트 추출 → 문장 단위 청킹 → fastembed 임베딩 → pgvector 인덱싱
  • RAG 챗봇은 찾은 문서를 근거로 붙여 답하고, korean-law-mcp(MCP 서버)로 산업안전보건법 조문을 실시간 조회해 없는 조문 인용(할루시네이션) 차단
  • ARQ·Redis 워커로 항목 분류 → 위험 등급·보완 평가 2단계 비동기 분석 파이프라인
  • VLM으로 현장 사진·TBM 회의록을 분석해 새 위험 요인 추출
  • 병합 셀·비정형 칼럼이 섞인 엑셀(.xlsx)·한글(.hwpx) 평가표 파싱, 편집형 그리드·대시보드, PDF·DOCX·XLSX 보고서 내보내기
