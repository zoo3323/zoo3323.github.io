라벨링 도구

현장 영상 수집, 카메라 캘리브레이션, 하단면 라벨링, 학습 세트 내보내기를 한 흐름으로 잇는 사내 웹 도구

NamJuKim

  • 회사신라이앤씨
  • 기간2026
  • 맡은 일도구 설계·개발

주차면 사각형·바닥 선 기반 카메라 보정, 지면 좌표계 하단면 라벨 편집·이미지 재투영을 지원하는 라벨링 도구 구축. 배포 모델 예측을 사전 라벨로 띄우는 모델 보조 라벨링과 학습 세트 버전 관리까지 한곳에 통합.

구성

  1. 프레임 수집현장 스냅샷 · 기둥 카메라 녹화
  2. 골라내기각도 변경 감지 · 중복 제거
  3. 카메라 보정어안 왜곡 · 지면 호모그래피 · 소실점
  4. 하단면 라벨링지면 좌표 · 차급 프리셋 · 모델 사전 라벨
  5. 학습 세트입력 규격 맞춤 내보내기 · 버전 기록

FastAPI 서버 + 웹 화면(JavaScript·Canvas)

풀어야 했던 문제

맡은 일

  • 현장 카메라 스냅샷·기둥 카메라 녹화 프레임 수집, 카메라 각도 변경 감지·화소 변화 기반 중복 제거 구현
  • 주차면 사각형 기반 OpenCV 어안 왜곡 계수·지면 호모그래피(homography) 추정, 소실점 기반 초점거리·카메라 높이·롤 보정 구현
  • 지면 좌표계 차급 프리셋 하단면 배치·원근 재투영, 실측 크기·비율 이탈 라벨 경고 기능 개발
  • 배포 모델(ONNX Runtime) 예측 기반 사전 라벨 제안(모델 보조 라벨링), 보정 변경 시 라벨 자동 재정렬
  • 모델 입력 규격(레터박스 등) 맞춤 학습 세트 내보내기·세트 버전 기록 기능 구축

쓴 기술

  • Python
  • FastAPI
  • OpenCV
  • ONNX Runtime
  • JavaScript · Canvas

자료

  • 바닥 주차선과 소실점 기반 초점거리·카메라 높이·기울기 보정생성 이미지

  • 보정값으로 바닥에 올린 2.5 m 격자와 차량 하단면 라벨(초록)생성 이미지
