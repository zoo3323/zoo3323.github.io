라벨링 도구

현장 영상 수집, 카메라 캘리브레이션, 하단면 라벨링, 학습 세트 내보내기를 한 흐름으로 잇는 사내 웹 도구

NamJuKim

  • 회사신라이앤씨
  • 기간2026
  • 맡은 일도구 설계·개발

라벨링용으로 주차면 사각형과 바닥 선에서 카메라를 보정하고, 하단면 라벨을 지면 좌표계에서 편집해 이미지로 재투영하는 라벨링 도구를 만들었습니다. 배포 모델의 예측을 사전 라벨로 띄우는 모델 보조 라벨링과 학습 세트 버전 관리까지 한곳에서 합니다.

구성

  1. 프레임 수집현장 스냅샷 · 기둥 카메라 녹화
  2. 골라내기각도 변경 감지 · 중복 제거
  3. 카메라 보정어안 왜곡 · 지면 호모그래피 · 소실점
  4. 하단면 라벨링지면 좌표 · 차급 프리셋 · 모델 사전 라벨
  5. 학습 세트입력 규격 맞춤 내보내기 · 버전 기록

FastAPI 서버 + 웹 화면(JavaScript·Canvas)

풀어야 했던 문제

  1. 문제하단면은 바닥에 가려 있어, 꼭짓점을 이미지에서 손으로 찍으면 차 크기와 방향이 들쭉날쭉해집니다.

    해결카메라를 보정해 지면 좌표에서 차급 프리셋(경차~대형) 하단면을 놓고 원근 그대로 재투영하며, 실제 차 크기를 벗어나면 경고합니다.

  2. 문제현장 카메라 영상을 처음부터 사람이 다 그리기에는 너무 느립니다.

    해결배포 모델의 예측을 사전 라벨로 띄워, 사람은 수락하거나 고치기만 합니다.

  3. 문제카메라 각도가 바뀌거나 비슷한 장면이 반복되면 같은 프레임이 쌓이고, 보정이 바뀌면 기존 라벨이 어긋납니다.

    해결각도 변경 감지와 화소 변화 기반 중복 제거로 프레임을 고르고, 보정이 확정되면 그 카메라의 라벨을 자동으로 다시 맞춥니다.

맡은 일

  • 현장 카메라 스냅샷·기둥 카메라 녹화에서 프레임 수집, 카메라 각도 변경 감지와 화소 변화 기반 중복 제거
  • 주차면 사각형으로 OpenCV 어안 왜곡 계수와 지면 호모그래피(homography) 추정, 소실점 기반 초점거리·카메라 높이·롤 보정
  • 지면 좌표계에서 차급 프리셋 하단면을 놓고 원근 그대로 재투영, 실측 크기·비율을 벗어난 라벨 경고
  • 배포 모델(ONNX Runtime) 예측을 사전 라벨로 제안하는 모델 보조 라벨링, 보정이 바뀌면 라벨 자동 재정렬
  • 모델 입력 규격(레터박스 등)에 맞춘 학습 세트 내보내기와 세트 버전 기록
