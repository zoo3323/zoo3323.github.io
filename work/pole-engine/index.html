주차폴 점유 판정 엔진

길가 주차폴(라즈베리파이 5)에서 하단면 모델로 주차면 점유와 입출차를 판정하는 엣지 엔진

  • 회사신라이앤씨
  • 기간2026
  • 맡은 일점유 판정·트래커 개발, 엣지 최적화

기존 사내 주차폴 엔진(번호판 인식·상태기계·펌웨어 연동)을 바탕으로 점유 판정을 차량 하단면 기반으로 바꾼 라즈베리파이 5 엣지 엔진. 폴 앞뒤 두 카메라의 하단면이 주차면 바닥을 덮은 비율로 입차·출차를 판정하고, 저속 프레임용 하단면 트래커와 차량 교체 판정 규칙 추가. 대구 칠곡 주차폴에 설치해 운영 중.

구성

  1. 폴 카메라

    앞 카메라흑백 센서
    뒤 카메라같은 칸 반대쪽
  2. 하단면 검출NCNN INT8 본체 · ONNX 디코더
  3. 하단면 트래커저속 프레임 ID 유지 · 차량 교체
  4. 점유 판정바닥 덮임 비율 · 입차 OR · 출차 AND
  5. 입출차 이벤트기존 상태기계 · 번호판 · 펌웨어

라즈베리파이 5 · 번호판 인식·상태기계·펌웨어 연동은 기존 엔진 그대로

풀어야 했던 문제

맡은 일

  • 하단면 트래커: 초당 1~2장에서도 같은 차 ID 유지, 앞뒤 카메라 ID가 함께 바뀌면 차량 교체 판정
  • 판정값 튜닝: 폴 36대의 하루 낮 영상 재생으로 기준값 선정, 점유 벤치마크 61대 중 60대 일치
  • 엣지 최적화: NCNN INT8 변환과 병목 제거로 모델 추론 126 → 68 ms, 엔진 처리 0.77 → 2.12 fps
  • 오프라인 오토라벨 도구: 같은 판정으로 녹화 영상을 재생해 학습용 주차 세션 자동 생성

정량 평가

점유 벤치마크
실제 주차 61대 재생, 1:1 일치 60대, 가짜 세션 16건, 점유 시간 정확도 99.69%
판정값 튜닝
폴 36대의 하루 낮 앞뒤 영상, 사람 라벨 194건
속도
사내 라즈베리파이 5에 실제 폴 구성 재현, CPU 상한 80%
