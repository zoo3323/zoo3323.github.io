노인보호구역 입지 분석

교통사고·노인 시설·도로·인구 공간 데이터를 분석해 경상북도 주요 시군의 노인보호구역 최적입지를 도출한 빅데이터 분석 사업

NamJuKim

  • 회사제이솔루션
  • 기간2024
  • 맡은 일프로젝트 담당 · 공간 데이터 분석

프로젝트 담당자로 공간 데이터 수집·전처리부터 모델링·시각화까지 주도. 핫스폿(Hot Spot) 분석으로 사고 다발 구역 도출, Random Forest·지리가중회귀(GWR)로 지역별 영향 차이(공간적 이질성)를 반영해 최적입지 도출.

구성

  1. 데이터 수집고령 보행자 사고 · 노인 시설 · 도로 · 인구
  2. 전처리Pandas · GeoPandas 자동화

  3. 공간 분석

    핫스폿·군집사고 다발 구역
    GWR · Random Forest지역별 영향 · 위험도
  4. 최적입지 제안QGIS 위험도 지도 · 보고서

Python · QGIS

풀어야 했던 문제

맡은 일

  • 고령 보행자 교통사고·노인 시설·도로 구조·인구 데이터 수집, Pandas·GeoPandas 전처리·분석 자동화 스크립트 개발
  • QGIS 행정구역·교통·인구·시설 레이어 통합, 사고 건수·시간대·도로 구조·시설 밀집도 기준 핫스폿·군집 분석 수행
  • scikit-learn Random Forest·GWR(지리가중회귀)로 공간적 이질성을 반영한 위험도 모델 구축
  • 위험도 지도·분석 보고서로 시군별 노인보호구역 최적입지 제안

쓴 기술

  • Python · Pandas · GeoPandas
  • scikit-learn(Random Forest)
  • GWR(지리가중회귀)
  • QGIS
  • 핫스폿 분석

자료
