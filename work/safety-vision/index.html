안전 영상 분석

사업장 CCTV의 RTSP 영상에서 안전모 미착용·화재·침입을 감지하고, 여러 카메라에 걸쳐 사람을 추적하는 실시간 영상 분석 서버

NamJuKim

  • 회사패턴앤
  • 기간2025
  • 맡은 일영상 분석 서버 개발

GPU 한 대에서 화재·안전모·침입 감지와 다중 카메라 추적 모델을 함께 운영하는 FastAPI 추론 서버를 만들었습니다. RTSP 스트림을 받아 추론하고, 결과를 하나의 스키마로 정규화해 WebSocket으로 실시간 송출합니다.

맡은 일

  • FastAPI 다중 모델 라우팅과 동적 모델 로딩: GPU에는 한 모델만 상주시키고 요청 시 교체해 VRAM 부족(OOM) 해결
  • RTSP 스트림 전용 스레드 디코딩과 자동 재연결, 결과를 box·roi·count 스키마로 정규화해 WebSocket 송출
  • YOLO 계열 검출로 화재·연기와 안전모 착용(helmet)·미착용(head) 감지
  • ArUco 마커로 침입 감지 ROI를 자동 생성해, 카메라를 다시 달아도 재설정 없이 동작
  • ByteTrack 추적과 ResNet50 ReID로 여러 카메라를 지나는 같은 사람에게 전역 ID 부여, 신뢰도 높은 트랙만 ReID해 GPU 부하 절감

쓴 기술

  • Python
  • FastAPI · WebSocket
  • PyTorch · YOLO
  • ByteTrack · ReID
  • OpenCV · ArUco
  • Docker · CUDA

자료

  • 안전모 착용(helmet)·미착용(head) 감지생성 이미지

  • 출입 금지 구역(ROI) 침입 감지생성 이미지
