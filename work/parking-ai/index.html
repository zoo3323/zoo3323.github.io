주차면 판단 AI

주차장 CCTV·기둥 카메라 영상에서 차량 하단면을 검출해 주차면 점유를 판단하는 AI 모델

NamJuKim

  • 회사신라이앤씨
  • 기간2026
  • 맡은 일모델 연구·개발, 엣지 배포

카메라 캘리브레이션 없이 이미지 한 장에서 차량 하단면(footprint)을 가려진 부분까지 볼록 사각형으로 검출하는 one-stage 모델을 연구·개발합니다. CARLA 합성 데이터와 실제 영상으로 학습하고, 지식 증류·INT8 양자화로 경량화해 라즈베리파이·Jetson·GPU 서버에 배포합니다.

맡은 일

  • CFQ 표현 설계: 차량 축 기준 앞뒤 변의 폭·기울기로, 꼭짓점 순서가 고정된 볼록 사각형을 항상 출력
  • 중심점 기반 one-stage 검출기로 가려진 꼭짓점까지 추정하는 amodal 하단면 검출, 대각선 길이로 정규화한 꼭짓점 손실
  • CARLA 합성 데이터(어안 포함) 학습과 실제 CCTV 미세조정, 열화·가림·야간 조명 증강으로 sim-to-real 격차 축소
  • 지식 증류(knowledge distillation)·INT8 양자화 후 ONNX·NCNN·TensorRT로 변환해 엣지 장비에 배포
  • 앞뒤 카메라의 하단면 트랙을 결합하고, 주차면 ROI를 덮는 비율로 입차·출차 판정
  • 현장 영상 재생 벤치마크로 오검출·미검출을 검증하고, 모델별 릴리스와 입출력 계약을 버전 관리

쓴 기술

  • Python
  • PyTorch
  • CARLA
  • ONNX · NCNN
  • TensorRT · DeepStream
  • 라즈베리파이 · Jetson
