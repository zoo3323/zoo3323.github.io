2.5D 차량 하단면 검출

주차장 영상에서 캘리브레이션 없이 차량 하단면을 검출해 주차면 점유를 판단하는 모델

NamJuKim

  • 회사신라이앤씨
  • 기간2026
  • 맡은 일모델 연구·개발, 엣지 배포

원본 영상 한 장에서 가려진 부분까지 차량 하단면(footprint) 네 꼭짓점을 바로 출력하는 one-stage 2.5D 검출 모델. 옆 칸까지 덮는 2D 상자 대신 바닥에 닿는 영역으로 주차면 점유를 판단하고, 카메라마다 하던 캘리브레이션·어안 왜곡 보정 단계 제거.

용어CFQConvex Footprint Quadrilateral

차량 축과 앞뒤 변의 폭·기울기로 늘 볼록한 사각형을 내는 하단면 표현.

논문 바로가기

구성

학습

  1. 데이터

    합성 데이터CARLA 주차장 · 어안 렌즈 포함
    실제 영상라벨링 도구로 만든 하단면 라벨
  2. 학습열화·가림·야간 조명 증강, 합동 학습·미세조정
  3. 경량화지식 증류 · INT8 양자화
  4. 모델 릴리스ONNX·NCNN · 입출력 계약 버전 관리

현장

  1. 원본 영상CCTV · 기둥 카메라, 보정 없이 그대로
  2. 2.5D 하단면 검출중심점 one-stage · CFQ 볼록 사각형
  3. 트래킹하단면 트래커 · 앞뒤 카메라 결합
  4. 점유 판정주차면 ROI를 덮는 넓이 → 입차·출차

라즈베리파이 · Jetson · GPU 서버(TensorRT·DeepStream)에서 동작

풀어야 했던 문제

맡은 일

  • 모델 설계부터 데이터셋·지표 설계, 실험, 정량 평가, 경량화·현장 배포까지 전 과정 주도, 투고 논문 제1저자
  • CFQ 표현 설계: 꼭짓점 순서가 고정된 볼록 사각형 출력 보장, 합성 검증 AP50:95 61.10 ± 0.52%(평행사변형 57.32%)
  • one-stage 검출기로 가려진 꼭짓점까지 추정하는 amodal 하단면 검출, CARLA 합성·실제 CCTV 합동 학습으로 sim-to-real 격차 축소
  • 품질·지연·비용 비교로 장비별 경량화 선택: GPU 서버 640 입력 + 지식 증류, 라즈베리파이 INT8 양자화
  • 앞뒤 카메라 하단면 트랙 결합, 주차면 ROI 점유 비율 기반 입차·출차 판정

정량 평가

데이터셋
CARLA 합성 230,865장 · 실제 CCTV 6,779장, 실제는 현장 단위로 학습·검증·시험 분할
지표
AP50·AP50:95·꼭짓점 오차·비정상 사각형 비율, 현장은 찬 칸 놓침·청구 시간 오차
가드레일
통과 기준 학습 전 고정, 시험셋 1회 개봉, 라즈베리파이 실기기 채점
불확실성
시드 3회 평균 ± 표준편차 보고, 시드별 순위 일치 확인
