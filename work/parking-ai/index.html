2.5D 차량 하단면 검출

주차장 CCTV·기둥 카메라 영상에서 카메라 캘리브레이션·왜곡 보정 없이 차량 하단면을 검출해 주차면 점유를 판단하는 2.5D 검출 모델

NamJuKim

  • 회사신라이앤씨
  • 기간2026
  • 맡은 일모델 연구·개발, 엣지 배포

카메라 캘리브레이션·어안 왜곡 보정 없이 원본 영상 한 장에서 차량 하단면(footprint) 네 꼭짓점을 가려진 부분까지 바로 출력하는 one-stage 2.5D 검출 모델 연구·개발. 카메라별 보정값 산출 단계 제거. CARLA 합성 데이터·실제 영상으로 학습하고 지식 증류·INT8 양자화로 경량화해 라즈베리파이·Jetson·GPU 서버에 배포.

구성

학습

  1. 데이터

    합성 데이터CARLA 주차장 · 어안 렌즈 포함
    실제 영상라벨링 도구로 만든 하단면 라벨
  2. 학습열화·가림·야간 조명 증강, 합동 학습·미세조정
  3. 경량화지식 증류 · INT8 양자화
  4. 모델 릴리스ONNX·NCNN · 입출력 계약 버전 관리

현장

  1. 원본 영상CCTV · 기둥 카메라, 보정 없이 그대로
  2. 2.5D 하단면 검출중심점 one-stage · CFQ 볼록 사각형
  3. 트래킹하단면 트래커 · 앞뒤 카메라 결합
  4. 점유 판정주차면 ROI를 덮는 넓이 → 입차·출차

라즈베리파이 · Jetson · GPU 서버(TensorRT·DeepStream)에서 동작

풀어야 했던 문제

맡은 일

  • 캘리브레이션 없는 2.5D 검출 구현: 카메라 내부·외부 파라미터, 어안 왜곡 보정, 지면 호모그래피 없이 원본 이미지에서 하단면 네 꼭짓점 직접 출력
  • CFQ 표현 설계: 차량 축 기준 앞뒤 변의 폭·기울기로 꼭짓점 순서가 고정된 볼록 사각형 출력 보장
  • 중심점 기반 one-stage 검출기로 가려진 꼭짓점까지 추정하는 amodal 하단면 검출 개발, 대각선 길이 정규화 꼭짓점 손실 설계
  • CARLA 합성 데이터(어안 포함) 학습·실제 CCTV 미세조정, 열화·가림·야간 조명 증강으로 sim-to-real 격차 축소
  • 지식 증류(knowledge distillation)·INT8 양자화로 경량화, ONNX·NCNN·TensorRT 변환 후 엣지 장비 배포
  • 앞뒤 카메라 하단면 트랙 결합, 주차면 ROI 점유 비율 기반 입차·출차 판정 구현
  • 현장 영상 재생 벤치마크로 오검출·미검출 검증 체계 구축, 모델별 릴리스·입출력 계약 버전 관리
